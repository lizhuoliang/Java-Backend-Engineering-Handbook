# 消息与通知类

## 本类定位

这一类主要解决系统里的“消息怎么发出去、怎么触达用户、失败后怎么补、异步后怎么治理”。

它不仅仅是“发短信”或“发邮件”，更重要的是：

- 通知能力怎么模块化
- 多种渠道怎么统一组织
- 失败和重试怎么治理
- 消息最终怎么闭环

## 适用场景

- 站内信系统
- 验证码与通知短信
- 邮件通知
- App / Web 推送
- 异步消息驱动通知
- 消息可靠性治理
