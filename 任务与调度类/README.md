# 任务与调度类

## 本类定位

这一类主要解决系统中的“后台自动执行能力”，也就是：

- 哪些任务要定时跑
- 哪些任务要延迟触发
- 哪些失败任务要重试
- 哪些业务异常需要补偿

如果说高并发与稳定性类更偏“系统扛住压力”，那任务与调度类更偏：

- 系统在没人手动干预时，也能自己把事做完

## 适用场景

- 定时对账、归档、清理
- 超时关单、延迟通知
- 失败任务重试
- 业务补偿修复
- 大批量后台处理

## 推荐阅读顺序

推荐顺序如下：

1. 定时任务
2. 延迟任务
3. 批处理任务
4. 失败重试机制
5. 补偿任务

理解顺序可以概括为：

- 先理解“时间触发”
- 再理解“对象到期触发”
- 再理解“大量数据任务”
- 最后理解“失败恢复链”
