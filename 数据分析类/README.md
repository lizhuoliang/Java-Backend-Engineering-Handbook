# 数据分析类

## 本类定位

这一类主要解决系统中的“数据怎么被沉淀、被统计、被展示、被导出、被长期管理”的问题。

它不直接产生业务，而是帮助系统回答：

- 系统发生了什么
- 用户做了什么
- 业务当前怎么样
- 历史数据还能不能继续支持分析

所以这一类更像是：

- 业务运行结果的观察层
- 长期数据治理层

## 适用场景

- 管理后台经营概览
- 业务运营统计
- 用户行为分析
- 报表导出
- 历史数据治理与归档

## 推荐阅读顺序

推荐顺序如下：

1. 操作日志
2. 用户行为分析
3. 业务统计
4. 数据看板
5. 报表导出
6. 数据归档

理解顺序可以概括为：

- 先采集基础事件
- 再抽取业务指标
- 再组织成看板和报表
- 最后考虑长期数据生命周期治理
