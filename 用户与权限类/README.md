# 用户与权限类

## 本类定位

这一类主要解决系统里的“人”和“权限”问题，也就是：

- 用户怎么进入系统
- 系统怎么确认用户身份
- 用户能看到什么、能做什么

这是大多数后台系统和业务系统最基础的一层。  
如果这一层没搭稳，后面的业务流程、数据权限、审计和风控都会很难做。

## 适用场景

这一类内容适合下面这些场景：

- 后台管理系统账号体系设计
- Web / App 登录注册体系搭建
- RBAC 权限模型落地
- 菜单、按钮、数据权限控制
- 单点登录与账号集成

## 推荐阅读顺序

推荐按下面顺序阅读，这样理解会更顺：

1. 用户注册
2. 用户登录
3. 用户退出
4. 认证鉴权
5. 角色权限管理 RBAC
6. 菜单权限
7. 按钮权限
8. 数据权限
9. 用户资料管理
10. 密码修改与找回
11. 单点登录 SSO

这一顺序本质上是：

- 先搭账号入口
- 再搭认证链路
- 再搭权限体系
- 最后再扩展账号治理和多系统登录
