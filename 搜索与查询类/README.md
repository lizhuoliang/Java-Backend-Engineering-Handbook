# 搜索与查询类

## 本类定位

这一类主要解决系统里的“数据怎么被查出来、怎么更快被找到、怎么更适合人使用”。

它不仅仅是写几条 SQL，更重要的是：

- 查询能力怎么组织
- 文本搜索和结构化筛选怎么区分
- 大数据量场景下什么时候该上搜索引擎
- 统计与报表查询怎么和普通列表查询分层

## 适用场景

- 后台列表检索
- 文章 / 商品 / 用户搜索
- 搜索建议和联想词
- 全文检索系统
- 报表型查询接口
