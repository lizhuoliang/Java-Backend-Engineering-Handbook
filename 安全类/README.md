# 安全类

## 本类定位

这一类主要解决系统里的“安全边界”问题，也就是：

- 谁能进来
- 请求是不是可信
- 数据能不能被安全地看见和修改
- 异常行为怎么被识别和阻断

它不是某个单独功能点，而是一层贯穿账号、接口、数据、操作和风控的系统性能力。

## 适用场景

- 登录入口保护
- 接口调用可信校验
- 敏感数据展示与导出控制
- 高风险操作审计
- 输入与页面安全治理
- 风控与异常行为识别

## 推荐阅读顺序

推荐顺序如下：

1. 登录安全
2. 接口签名
3. 防 SQL 注入
4. 防 XSS
5. 防 CSRF
6. 数据脱敏
7. 敏感操作审计
8. 异常行为识别
9. 风控

理解顺序可以概括为：

- 先守住入口和接口
- 再守住数据和页面
- 最后进入行为层面的安全治理
