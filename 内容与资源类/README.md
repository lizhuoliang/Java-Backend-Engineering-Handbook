# 内容与资源类

## 本类定位

这一类主要解决系统里的“文件、图片、附件、文档、富文本内容”等资源如何被上传、存储、预览、引用和长期管理。

它的核心问题不是单纯“能不能传一个文件”，而是：

- 文件怎么存
- 怎么查
- 怎么预览
- 怎么和业务对象关联
- 怎么做版本和生命周期管理

## 适用场景

- 附件系统
- 图片资源系统
- 对象存储接入
- 富文本编辑器资源管理
- 合同、文档、资料类资源平台

## 推荐阅读顺序

推荐顺序如下：

1. 文件上传
2. 文件下载
3. 附件管理
4. 图片管理
5. 富文本内容存储
6. 对象存储对接 OSS / MinIO
7. 文档预览
8. 文件版本管理

理解顺序可以概括为：

- 先把文件基础链路打通
- 再处理文件与业务的关系
- 最后处理更复杂的预览、版本和对象存储演进
