# 基础数据管理类

## 本类定位

这一类主要解决系统中最常见、最基础的“数据维护”问题。  
它是很多业务模块的底座，核心关注点包括：

- 数据怎么增删改查
- 列表怎么筛选、排序、分页
- 字典、参数、组织、部门、岗位等基础信息怎么管理

如果说用户权限类解决的是“谁在用系统”，那基础数据管理类解决的就是：

- 系统里的基础数据怎么被维护和组织

## 适用场景

- 管理后台基础模块开发
- 通用 CRUD 框架搭建
- 树形结构、字典、组织类数据建模
- 导入导出型后台能力实现

理解顺序可以概括为：

- 先掌握列表和数据维护的基础能力
- 再掌握树形和组织类结构
- 最后再扩展成批量处理和配置管理

## 与其他大类的关联
