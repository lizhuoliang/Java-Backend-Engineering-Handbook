# 开放平台与集成类

## 本类定位

这一类主要解决系统和“边界之外”的平台、系统、合作方如何安全、稳定、可追踪地交互。

和前面更多偏内部能力的模块不同，这一类内容面对的是：

- 外部身份
- 外部支付
- 外部消息通道
- 外部业务系统
- 对外开放 API

所以它更强调：

- 协议
- 鉴权
- 回调
- 同步
- 兼容性

## 适用场景

- 第三方身份接入
- 支付渠道接入
- 地图、短信、邮件平台对接
- Webhook 事件回调
- 系统间数据同步
- 对外 API 开放

## 推荐阅读顺序

推荐顺序如下：

1. 第三方登录
2. Webhook 回调
3. 短信平台对接
4. 邮件平台对接
5. 地图服务对接
6. 支付接口对接
7. 外部系统同步
8. API 开放平台

理解顺序可以概括为：

- 先看身份与回调这两类基础集成
- 再看通道型平台对接
- 再进入支付和系统级集成
- 最后看对外能力平台化
